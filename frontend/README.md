# TapeLab frontend

A small React + TypeScript page that reads the Java backend (`../backend`).

    npm install
    npm run dev      # http://localhost:5173, API calls are forwarded to the backend on :8081
    npm test         # unit tests
    npm run build    # type-check and build into dist/

Start the backend first (`cd ../backend && ./mvnw spring-boot:run`).
